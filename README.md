# Sample Repository

A simple starting point for keeping your files organised.

## Folder structure

```text
review-demo/
|-- README.md
`-- organisation/
    `-- sample-notes.md
```

## Getting started

1. Put your documents, notes, and other files in `organisation/`.
2. Rename or replace `organisation/sample-notes.md` with your own content.
3. Add subfolders as needed, such as `organisation/projects/` or `organisation/documents/`.

Use descriptive filenames, such as `meeting-notes.md` or `project-plan.md`.
